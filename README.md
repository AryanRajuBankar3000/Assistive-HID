# Assistive HID for Motor Disabilities

## Overview
This project is an Assistive Human Interface Device (HID) designed to empower individuals with severe motor disabilities (specifically those with mobility restricted to above the neck). The device translates accessible inputs—such as head movements or breath pressure—into standard computer mouse control, providing a hands-free navigation experience.
